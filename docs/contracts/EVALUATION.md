# Batch A 评估与冻结契约

| 数据集 | 主选择指标 | 同时报告 |
| --- | --- | --- |
| GoEmotions | Validation Macro-F1，按冻结的 28 标签等权平均 | Micro-F1、Samples-F1、逐标签 P/R/F1/support、Hamming Loss、Subset Accuracy 和适用的 PR-AUC。按 train 标签支持量分层解释类别不平衡。 |
| 中文电影评论 | Validation Macro-F1，两个语义类别等权平均 | Accuracy、语义正类 P/R/F1、两类 F1/support、混淆矩阵和适用的 ROC-AUC/PR-AUC。针对模型差额计算配对置信区间。 |

## 阈值、Epoch 与模型选择

1. 每个有效 epoch 用 validation 预测枚举一个全局阈值。GoEmotions 的同一阈值应用到全部 28 标签，中文用一个二分类阈值。SVM margin 候选从 −1.50 到 1.50、步长 0.10，默认阈值 0。Sigmoid 候选从 0.05 到 0.95、步长 0.05，默认阈值 0.50。两端包含，预测规则采用 `score >= threshold`，候选通过整数刻度构造。
2. 阈值、最佳 epoch、早停、HPO 排名及循环模型对照选择统一最大化 Validation Macro-F1。F1 的零分母记 0。分数平分判定容差为 1e-12。阈值平分优先距离默认阈值最近，再取较小者；epoch 平分保留较早者；Trial 平分优先基础配置，其次较小 Trial 编号；循环模型平分按矩阵顺序。
3. 记录每个 epoch 的最佳阈值与指标，并持久化获选 checkpoint 的阈值搜索和决策记录。保存 margin 或 sigmoid 的分数类型与标签列顺序。应用所有冻结阈值前核对该分数类型。仅在无足够类别定义的情况下将 AUC 标为缺失并保留原因。已有独立 E1 验证工具走兼容路径，Batch A 候选须走统一口径。

## 重复性和不确定性

- 复验基于 validation 选择的配置。固定超参数，每个 seed 用同一规则重新选 epoch 和阈值。对三个指定 seed 的验证与正式测试指标分别报告逐 seed 的值、均值、样本标准差（ddof=1）和有效 `n`。主结果表仍引用独立的 seed 42 主 Run。复验不足三个时记录缺项，按实际有效 `n` 展示，`n<2` 时标准差不可用。
- 每数据集允许最多一个可选三次训练区块。优先处理通过质量验收但复验 Macro-F1 样本标准差达到 0.02 的配置，按标准差降序、再按矩阵顺序选一个，并用 52/62/72。若无该情况，且下一名循环模型与获选者的首轮验证 Macro-F1 差不超过 0.01，复验该循环模型的 42/123/2026。高方差追加种子单列，并可附全样本统计。数值、泄漏或产物异常走质量诊断和重试预算。
- 中文对 `E2−E1`、验证获选循环模型 `−E2`、`E5-TUNE−E2`、`E5-FROZEN−E2`、`E5-TUNE−E5-FROZEN` 使用同一个冻结 seed 42 主批次。先按样本 ID 对齐两模型的标签和预测，再按真实类别分层有放回抽样，比较模型使用相同抽样索引。采用 10,000 次、seed 20261117、95% 百分位区间，汇报 Macro-F1 差值、方向、区间与样本数。事先固定对照名单，区间含零时报告观察到的差额和区间。
- GoEmotions 汇报全部类别的 train/test support 和测试 F1。train 正例数低于 50 的类别列为稀有类别。稀有类别在 test 正例数至少 10 时用逐样本整行重抽样估计 F1 区间，保留同一条样本的所有标签；支持量不足时列样本量及逐类结果。区间描述测试集抽样波动，跨 seed 的样本标准差描述训练稳定性。

## 正式测试门禁

1. Stage 0 由数据审计读取 test，只产出格式、哈希、分区隔离与聚合统计。Stage 3 仅提供 train/validation 与训练所需指纹，禁止读 test。
2. Stage 4 的独立审核使用冻结前证据，复算验证指标，审核 14 个主 Run 和将进入正式评估的复验 Run。固定数据与预处理版本、模型与 checkpoint、阈值、配置、评估器版本、复验与统计对照名单。任一主结果位或必选复验缺失或未通过质量验收时保留状态，暂停冻结。
3. 使用完整冻结清单一次进入正式测试。评估入口先核对清单与产物指纹，再读取对应 test。成功输出禁止覆盖；故障后只在同一冻结版本补齐未完成项。正式测试之后的汇总完全从原始预测重算，模型和参数选择以冻结记录为准。
