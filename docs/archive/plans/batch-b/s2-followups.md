# Batch B S2 · 三种子稳定性与 B1 训练预算

S2 使用 S1 的官方权重、Tokenizer、冻结 train/validation、标签映射、阈值网格和精度。B2、B3、B4 的种子 42 沿用 S1 入选 Run，各加 Seed 123、2026。B4 的目标是中文任务的稳定性估计。B1 在选定训练预算后也加两个种子。所有新增 Run 均从官方预训练权重和新分类头开始，同一 Run 的中断恢复沿用原协议。

## S1 实测入口

| 现象 | 证据 | 待评估 |
| --- | --- | --- |
| 英文排名稳定性 | 入选 B2 验证 Macro-F1 为 0.5305，B3 为 0.5285，相差 0.0020。两组均在第 4 轮早停，最佳同为第 2 轮。 | 优先评估固定入选超参数的匹配种子复验。B2 入选 Run 用时 10.58 分钟，B3 为 19.72 分钟。 |
| B1 停止边界 | 入选 Run 在第 5 轮达到 0.495810，第 6 轮为 0.495794，达到上限时差值很小。 | 根据报告是否需要收敛边界证据，决定是否做一次短延长。 |

## 固定执行矩阵

| 配置 | Seed 42 | Seed 123、2026 |
| --- | --- | --- |
| B1 | S1 入选 LR 3e-5，以 12 Epoch、Patience 3 独立重训，验证 Macro-F1 提升至少 0.0100 时采用新预算 | 复验上栏入选的预算和超参数 |
| B2 | S1 入选学习率 3e-5 | 相同配置 |
| B3 | S1 入选学习率 2e-5 | 相同配置 |
| B4 | S1 入选学习率 3e-5 | 相同配置 |

B1 的 12 轮协议重新建立 Linear Scheduler。以实际 1,351 steps/epoch 与 6% warmup 计算，6 轮和 12 轮分别计划 8,106 和 16,212 个更新，warmup 分别为 487 和 973 步。验证增益按 seed 42 各协议最佳轮次及阈值比较。精确分数用于判断，低于门槛或平分时沿用原 6 轮协议。两条轨迹都归档，独立训练预算比较允许前六轮不同。

正式队列共 9 个新增槽位。复验沿用入选设置和既有 CUDA 预检，比较组按同一批次协议执行。汇总报告展示逐种子值、均值、样本标准差（ddof=1）及同数据集排名。GoEmotions 汇报 Micro-F1、Subset Accuracy、全部标签 F1 与支持量。按 train 正例支持量选最低五类，平分按标签顺序。以每类 F1 差除以总标签数分解 B2−B3 的 Macro-F1 差，并重算去掉最低支持组后的描述性排名。诊断使用各 Run 已选阈值，正式选模仍使用完整 28 标签 Macro-F1。

拟冻结清单列四个 seed 42 主 Run 和八个复验 Run，固定各自配置、权重、阈值、标签和指纹。B1 主 Run 由上述预算判据确定。正式测试另行完成冻结审计后执行。S3 继续独立规划。 [S1 结果](../../../reports/batch-b-s1/report.md) · [S2 配置](../../../configs/experiment_suites/batch_b_s2.yaml)
